# LifeRoute Platform Architecture

## System Overview
- **Core Platform**: Modern React 18 + TypeScript + Vite + Tailwind CSS + TanStack Start.
- **Independence**: Fully self-contained, open-source architecture with zero external platform lock-in.
- **Deployment**: Single-command deployment ready for Vercel, Netlify, Cloudflare Pages, Docker, and Static web hosts.
- **PWA / App Support**: Native Web App Manifest, Service Worker caching, and Capacitor mobile configurations.
